LCA – Life Cycle Assessment System
A responsive front-end prototype for a college Front-End Development project.
Features
Modern responsive dashboard
Project management table with search and status filter
New LCA assessment form
Simplified life-cycle inventory inputs
Automatic educational carbon-footprint calculation
Stage contribution visualization
Results dashboard
Report generation and browser print
Light/dark theme
No backend required
Technologies
HTML5
CSS3
Vanilla JavaScript
CSS Grid/Flexbox
Browser Local Storage for theme preference
Important note
This is an educational front-end prototype. The impact coefficients are simplified illustrative values and are not a substitute for a certified LCA methodology or validated LCA database.
Run
Open index.html in a browser, or use VS Code Live Server.
